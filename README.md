# 🎬 YMPlayer — Plex 스타일 독립형 동영상 플레이어

Plex 서버, IPTV(M3U + XMLTV 편성표), **텔레그램 채널 동영상**을 **한 화면에서** 보는 독립 실행형 웹 플레이어입니다.
북오아시스 `ym_m3u_player` 플러그인의 재생 엔진(hls.js / mpegts.js / 네이티브)과 M3U·EPG 처리를
그대로 옮겨 오고, 화면은 Plex 웹처럼 다시 만들었습니다. 북오아시스 없이 파이썬 하나로 돕니다.

## 실행

```bash
git clone https://github.com/yume-script/ym_player
cd ym_player
python3 -m venv .venv                 # Ubuntu/Debian은 시스템 pip 설치를 막아서 venv를 쓴다
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m ym_player         # http://127.0.0.1:8899
```

`python3 -m venv`가 안 되면 먼저 `sudo apt install python3-venv`.
텔레그램의 mkv·HEVC·AC-3 영상까지 보려면 **ffmpeg**도 깔아 두세요: `sudo apt install ffmpeg` (없어도 나머지는 그대로 돕니다).
테스트: `.venv/bin/pip install pytest && .venv/bin/python -m pytest -q`

### 서버가 켜질 때 자동 실행 (systemd)

`deploy/ym_player.service`는 저장소가 `/mnt/ym_player`에 있다고 가정합니다. 다른 곳이면 파일 안의
`WorkingDirectory`/`ExecStart` 두 줄만 고치세요.

```bash
sudo cp deploy/ym_player.service /etc/systemd/system/
sudo cp deploy/ym_player.env.example /etc/ym_player.env
sudo chmod 600 /etc/ym_player.env
sudo nano /etc/ym_player.env          # MP_USER / MP_PASSWORD 바꾸기
sudo systemctl daemon-reload
sudo systemctl enable --now ym_player
```

상태와 로그: `systemctl status ym_player`, `journalctl -u ym_player -f`.
코드를 업데이트한 뒤에는 `git pull && sudo systemctl restart ym_player`.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `MP_HOST` / `MP_PORT` | `127.0.0.1` / `8899` | 집 안 TV·폰에서 보려면 `MP_HOST=0.0.0.0` |
| `MP_USER` / `MP_PASSWORD` | (없음) | 사용자가 아직 없을 때 이 아이디/비밀번호로 **첫 관리자**를 만듭니다 (없으면 첫 접속 화면에서 만듦) |
| `MP_DATA_DIR` | `ym_player/data` | 설정 파일(`config.json`) 위치. git에 안 올라감 |

### 로그인과 사용자

- 처음 접속하면 **관리자 계정 만들기** 화면이 나옵니다. 이후로는 로그인 화면에서 아이디/비밀번호로 들어옵니다
  ("로그인 유지"를 켜면 30일, 끄면 브라우저를 닫을 때까지).
- **관리자**: 사이드바 맨 아래 ⚙️ **설정**에서 탭으로 관리합니다 — **소스** / **사용자**(추가·삭제, 권한, 비밀번호, 볼 수 있는 범위) /
  **상태**(소스마다 실제 연결 점검, 서버 정보, 최근 경고) / **캐시** / **화면**(왼쪽 위 이름과 아이콘 - 로그인 화면과 브라우저 탭에도 쓰임, 아이콘의 버전 배지 켜기/끄기, 모든 사용자의 **기본 테마**) /
  **백업**(설정·사용자·즐겨찾기·아이콘을 JSON으로 받기, 그 파일로 복원) / **Thanks to**(참고한 저장소, 쓰는 오픈소스, 변경 이력).
- **버전**: `ym_player/__init__.py`의 `__version__` 한 곳에서 정합니다. 왼쪽 위 아이콘 배지(예: 1.1.14), 설정 > 상태,
  시작 로그에 그대로 나오므로 버전을 올릴 때 아이콘 그림을 다시 만들 필요가 없습니다(배지는 화면에서 글자로 얹음).
  업데이트(PR)마다 셋째 자리를 하나씩 올리고, `web/js/credits.js` CHANGELOG 맨 위 줄에 같은 `version`을 적습니다.
- **새 버전 알림**: 아이콘 옆에 **[NEW]**가 뜨면 아직 안 본 새 버전입니다. 누르면 그 뒤로 새로워진 점이 나오고, 본 버전은 사람마다
  서버에 기억합니다(다른 기기에서도 다시 안 뜸). 화면을 열어 둔 사이 서버가 업데이트되면 **[업데이트]**가 떠서 새로고침을 안내합니다
  (10분마다, 그리고 탭으로 돌아올 때 서버 버전을 확인).
- **GitHub 새 버전 알림 (관리자)**: 서버가 6시간마다 GitHub(`main`)의 `__version__`을 확인해서, 이 서버보다 새 버전이 올라와 있으면
  관리자 화면의 아이콘 옆에 **[GitHub]**가 뜹니다. 누르면 바뀐 점과 서버에서 칠 업데이트 명령(`git pull` + 재시작, [복사])이 나옵니다.
  설정 > 상태 > 업데이트에서 [지금 확인]으로 바로 확인할 수 있고, `MP_UPDATE_CHECK=0`이면 자동 확인을 끕니다.
  공개 저장소라 토큰이 필요 없고, 서버는 raw.githubusercontent.com에서 파일 두 개만 읽습니다(업데이트를 스스로 하지는 않음).
- **테마**: 다크(기본) / 라이트 / 블랙(OLED) / 네이비 / 시스템 따라(기기 설정에 맞춰 다크↔라이트) 중에서 고르고,
  강조색(주황·파랑·초록·보라·빨강·분홍·청록)을 따로 고릅니다. 관리자가 설정 > 화면에서 기본값을 정하고, 각 사용자는
  사이드바 아래 팔레트 버튼으로 자기 테마를 고릅니다(서버에 사람마다 저장되어 어느 기기에서나 같음). 재생 화면은 늘 어둡게 둡니다.
- **사용자**: 보기만 합니다. 설정 메뉴가 안 보이고 주소로 들어가도 막힙니다. 서버도 설정 저장/사용자 관리/Plex 로그인/텔레그램 로그인을
  관리자만 하게 막고, 사용자에게는 M3U 주소·Plex 서버 주소·API ID 같은 값을 내려주지 않습니다. Plex 중계도 읽기와 재생기의
  자막 선택 저장만 허용합니다.
- **볼 수 있는 범위**: 사용자마다 [전부 보기] 버튼으로 볼 소스, Plex 라이브러리, 텔레그램 채널을 고릅니다(예: 아이 계정은 "애니" 라이브러리와 채널 하나만).
  서버가 지키므로 고르지 않은 소스는 목록에서 빠지고, 고르지 않은 라이브러리·채널의 항목은 홈·검색·이어보기에서 빠지며 주소를 알아도
  열리지 않습니다 (원본 파일·자막도 그 사용자에게 보여준 항목의 것만).
- **IPTV 즐겨찾기**는 사람마다 서버(`data/prefs.json`)에 저장되어 어느 기기에서 로그인해도 같습니다.
- 모두 사이드바 맨 아래에서 **비밀번호 변경**과 **로그아웃**을 할 수 있습니다. 비밀번호를 바꾸면 그 사람의 다른 기기 로그인은 끊깁니다.
- 백업 파일에는 Plex 토큰·텔레그램 API Hash·비밀번호 해시가 들어 있으니 안전하게 보관하세요. 텔레그램 로그인 세션과 색인은
  들어가지 않습니다(다른 서버로 옮기면 텔레그램은 다시 로그인).
- 텔레그램 **이어보기는 사람마다 따로** 기록합니다. Plex는 서버 하나의 토큰으로 보기 때문에 시청 기록을 모두가 같이 씁니다.
- 계정은 `data/users.json`(비밀번호는 PBKDF2 해시만), 로그인 쿠키 서명 키는 `data/secret.key`에 있습니다. 로그인 실패가 IP마다
  10분에 10번을 넘으면 잠시 막습니다.
- 예전처럼 `MP_USER`/`MP_PASSWORD`를 넣어 두었다면, 처음 시작할 때 그 계정이 관리자로 만들어집니다.

처음 열면 소스가 없으니 사이드바 맨 아래 ⚙️ **설정**에서 추가합니다.

- **Plex 계정으로 추가**: plex.tv 로그인 창이 뜨고, 허용하면 계정에 연결된 서버와 접속 주소(로컬/원격/릴레이)
  목록이 나옵니다. 하나 고르고 **[저장]**.
- **Plex 직접 입력**: 서버 주소(`http://192.168.0.10:32400`)와 `X-Plex-Token`.
- **가져올 라이브러리**: 저장된 Plex 소스에는 라이브러리 체크 목록이 나옵니다. 체크를 끈 라이브러리는 사이드바·홈·검색에서
  빠집니다. 끈 것만 기억하므로 나중에 Plex에 새로 만든 라이브러리는 기본으로 보입니다.
- **텔레그램 추가**: [my.telegram.org](https://my.telegram.org) → *API development tools*에서 받은 **API ID / API Hash**와
  전화번호를 넣고 **[저장]** → 같은 카드에서 **[인증 코드 받기]** → 텔레그램 앱으로 온 코드 입력 → (2단계 인증을 쓰면) 비밀번호.
  로그인되면 들어가 있는 채널/그룹 목록이 나오고, 체크한 채널이 사이드바에 라이브러리처럼 붙습니다(체크 후 다시 [저장]).
- **IPTV 추가**: M3U 주소 + (선택) XMLTV 편성표 주소. `.xml.gz`도 됩니다.
- **라디오 추가**: 인터넷 라디오 방송국 목록 (아래 "인터넷 라디오").
  - **여러 M3U 합치기**: M3U 칸에 주소를 한 줄에 하나씩 넣으면 한 채널 목록으로 합칩니다(`#`로 시작하는 줄은 메모).
    뒤 목록의 채널이 앞 목록에 이미 있으면(같은 tvg-id, 같은 이름, 같은 주소) 한 번만 보이고, 뒤 주소는 **예비 주소**가 되어
    앞 주소가 안 나오면 재생기가 차례로 시도합니다(재생 화면 아래에 "예비 주소 1/2"). 일부 목록을 못 받아도 나머지로 보여 주고,
    설정 > 상태에 "M3U 2/3개 받음"과 실패한 주소가 나옵니다. EPG 칸도 여러 줄이면 합칩니다(같은 채널은 위 편성표 우선).

## 화면

| 화면 | 내용 |
|---|---|
| 사이드바 | 소스(Plex 서버·IPTV)별 메뉴. 소스가 둘 이상이면 하나를 펼치면 나머지는 접힘(펼친 상태 기억, 보고 있는 화면의 소스는 자동으로 펼침) |
| 홈 | 맨 위에 **모든 소스를 합친 이어보기**(Plex 이어보기·다음 에피소드 + 텔레그램, 최근에 본 순), 그 아래 소스마다 허브: Plex 최근 추가, IPTV의 즐겨찾는 채널 · 지금 방송 중. 오른쪽 위 **[랜덤 재생]**: Plex·텔레그램 전체에서 안 본 것 위주로 아무거나 계속 재생 |
| 라이브러리 | Plex 섹션별 **추천** 탭(섹션 허브) / **라이브러리** 탭(정렬, 안 본 것만, 스크롤하면 더 불러옴). **[랜덤 재생]**: 그 라이브러리(텔레그램은 채널)에서 아무거나 - 영화는 영화, TV는 에피소드 중에서, Plex는 [안 본 것만]을 따름 |
| 상세 | 흐린 배경 그림 + 포스터, 정보, **재생 / 이어보기 / 처음부터 / 봤음 표시**, 시즌·에피소드 목록, 출연진 |
| 라이브 TV | Plex Live TV식 **편성표 격자**(8시간, 현재 시각 선), 그룹/검색/⭐즐겨찾기/안 나온 채널 숨기기. 사이드바의 "라이브 TV"(모든 IPTV 소스 합친 편성표)는 IPTV 소스가 2개 이상일 때만 보이고, 하나면 그 소스의 "채널 편성표"만 |
| 검색 | 모든 소스에 동시에: Plex 검색 + 채널명·지금 방송 제목 |
| 재생기 | 전체화면 재생, 자동으로 숨는 컨트롤, 탐색 막대, **자막 메뉴**, Plex **음성 트랙·화질** 메뉴, 라이브 OSD, 채널 목록 서랍, **뒤로 가면 미니 플레이어로 접힘**, **화면 속 화면(PiP)으로 바꾸면 재생 화면을 접고 홈으로**, **재생 중 다른 탭(Chrome)·홈 화면(아이패드 Safari)으로 가면 자동 PiP**(돌아오면 보던 화면 그대로. Chrome은 주소창 왼쪽 사이트 설정의 "자동 PIP"가 허용이어야 함)(작은 막대의 [크게 보기]로 복귀, IPTV는 PiP 동안 화질 고정이라 창 크기를 바꿔도 되돌아가지 않음) |

### 재생기 단축키

| 키 | 동작 |
|---|---|
| Space / K | 재생 · 일시정지 |
| ← / → | 10초 뒤로 / 30초 앞으로 (VOD) |
| ↑ / ↓ | 이전 / 다음 채널 (라이브) · 볼륨 (VOD) |
| F, 화면 두 번 클릭 | 전체화면 |
| M | 음소거 |
| I | 채널 정보(OSD) 다시 보기 |
| C | 자막 메뉴 (VOD) |
| N | 다른 랜덤 영상 (랜덤 재생 중) |
| Esc | 채널 서랍 닫기 → 미니 플레이어로 접기 |
| / | 검색창으로 (재생기 밖에서) |

## 구조

```
ym_player/                       저장소 루트
├── requirements.txt
├── tests/                       test_ym_player.py, test_subtitles.py, test_telegram.py, test_auth.py
└── ym_player/                   파이썬 패키지 (python -m ym_player)
    ├── server.py                aiohttp 서버 - 정적 파일 + 아래 API
    ├── iptv.py                  M3U 파싱, XMLTV 파싱(iterparse, gzip), HLS 재생목록 주소 바꾸기 (순수 함수)
    ├── config_store.py          data/config.json 읽기/쓰기, 토큰 숨기기
    ├── auth.py                  사용자(users.json)·비밀번호 해시·로그인 쿠키·실패 제한·볼 수 있는 범위
    ├── prefs.py                 사용자별 작은 설정(prefs.json) - IPTV 즐겨찾기
    ├── subtitles.py             자막 SRT/SMI/ASS/VTT -> WebVTT 변환 (순수 함수)
    ├── telegram_src.py          텔레그램: Telethon 로그인/채널/색인(SQLite)/Range 스트림/썸네일/이어보기
    ├── transcode.py             ffprobe로 보낼 방법 정하기 + ffmpeg 명령 (서버 변환)
    ├── radio.py                 인터넷 라디오: 곡 정보(ICY) 읽기, iTunes 앨범 표지 고르기
    ├── media_cache.py           동영상 조각 캐시(디스크/메모리) + 앞쪽 미리 받기
    └── web/
        ├── index.html
        ├── css/app.css          Plex 다크 테마
        └── js/
            ├── app.js           사이드바 + 해시 라우터
            ├── player.js        재생 엔진 + 전체화면/미니 플레이어
            ├── visualizer.js    라디오 시각화(Web Audio 분석 + 캔버스) / LP 잡음
            ├── credits.js       설정 > Thanks to: 참고한 저장소, 오픈소스, 변경 이력 (PR을 머지하면 맨 위에 한 줄)
            ├── cards.js         포스터·채널 카드, 가로 줄
            ├── providers/
            │   ├── index.js     소스 종류 등록소
            │   ├── plex.js      Plex 소스
            │   ├── telegram.js  텔레그램 채널 소스

```

### 소스(provider) 모양

화면은 소스 종류를 모르고 아래 메서드만 부릅니다. 새 종류(Jellyfin, Emby 등)를 붙이려면 같은 모양의 클래스를
`web/js/providers/`에 만들어 `index.js`의 `TYPES`에 넣고, 서버 `config_store.SOURCE_TYPES`/`_clean_source`와
설정 화면 입력 칸만 추가하면 됩니다.

```
getLibraries()        -> [{id, title, type, icon}]          사이드바

getLibraryItems(...)  -> {items, total}                     (Plex만)
getPlayback(id|채널)  -> {url, kind: 'hls'|'ts'|'direct', live, proxyUrl?, startTime,
                          onProgress(state, sec), onStop(sec), getNext()}
```

## 인터넷 라디오

설정 > 소스 > **[라디오 추가]**. 방송국 칸을 비워 두고 저장하면 공개 재즈 방송국 3개(RelaxingJazz, Radio Swiss Jazz,
Jazz24)가 들어갑니다. 방송국은 한 줄에 하나 `이름 | 스트림 주소 | 설명 | 홈페이지`로 더하거나 뺄 수 있습니다. 스트림은 MP3·AAC·Ogg(Icecast·SHOUTcast)와 HLS(`.m3u8`) 둘 다 됩니다(곡 정보는 ICY를 주는 방송만). 방송국 줄 끝에 `| 분류`를 붙이면(예: `| 부산·경남`) 방송국 화면에서 **지역(분류)별로** 골라 봅니다. 설정의 **[한국 지역 라디오 넣기]**는 KBS·MBC·SBS 지역국, EBS, CBS, TBN, 공동체 라디오 등 194개(전국 + 서울·경기, 강원, 대전·충남, 충북, 전북, 광주·전남, 대구·경북, 부산·경남, 제주 - radio.bsod.kr 지역별 목록)를 분류와 함께 더합니다. 주소가 `.m3u8`로 끝나지 않아도 HLS로 나오는 방송은 처음 한 번 알아서 HLS로 다시 열고 기억합니다. 라디오를 **화면 속 화면(PiP)**으로 띄우면 영상 대신 앨범 표지·시각화·곡 이름을 그린 창이 뜹니다(Chrome·Edge 등 `canvas.captureStream`을 지원하는 브라우저, 안 되면 예전처럼).

- 홈에 "라디오" 줄, 사이드바에 **방송국** 화면. 카드에 지금 나오는 곡(♪ 가수 - 제목)이 보이고, 누르면 바로 재생합니다.
- 재생은 IPTV 라이브와 같은 재생기: 위/아래로 다른 방송국, 채널 목록, 즐겨찾기, 미니 플레이어(다른 화면으로 가도 계속).
  화면에는 앨범 표지가 크게 나오고 곡이 바뀌면 부제와 표지도 바뀝니다(20초마다 확인).
- 곡 정보는 방송 스트림에 섞여 오는 ICY 정보를 서버가 15초마다 읽고, 앨범 표지는 iTunes 검색에서 가수·제목이 맞는 곡을
  찾습니다(1시간 캐시). 곡 정보를 보내지 않는 방송국은 설명만 보입니다.
- **시각화**: 재생 화면 아래 [시각화] 메뉴(또는 시각화를 누르기)에서 스펙트럼 / 거울 막대 / 파형 / VU 미터(좌·우 바늘,
  재생 표시등) / 보케 입자 / 끄기를 차례로 고릅니다(브라우저에 기억). 소리를 서버 중계(같은 사이트 주소)로 받아서 브라우저가
  분석할 수 있으므로 아이패드 Safari에서도 음악에 반응합니다. 중계가 안 되면 방송국에 바로 연결하고, 그때는 분석이 막혀
  시각화가 기본 움직임으로 바뀝니다.
- **아이폰·아이패드 백그라운드 재생**: 화면을 끄거나 다른 앱으로 가도 계속 들리도록, 아이폰·아이패드에서는 기본으로 소리를
  Web Audio로 보내지 않습니다(그래서 시각화는 기본 움직임). [시각화] 메뉴의 "음악에 맞춰 움직이기"를 켜면 시각화가 음악에
  반응하지만, iOS가 백그라운드에서 Web Audio를 멈추면 소리도 끊길 수 있습니다.
- **잠금 화면·제어 센터**: 재생 중인 방송국·곡·앨범 표지가 잠금 화면에 나오고, 재생/일시정지와 이전/다음(라이브는 방송국,
  영상은 10초 뒤로/30초 앞으로)을 거기서 조작합니다 (Media Session, 라디오·IPTV·Plex·텔레그램 모두).
- **LP 잡음**: [LP 잡음] 버튼으로 켜고 끕니다. 켜면 강도(0~100%, 기본 30%) 칸이 잠깐 나타납니다. 브라우저에서 만든 히스와
  탁탁 튀는 소리를 20초 분량 반복하며, 재생 중일 때만 들리고 미니 플레이어로 접어도 계속됩니다. 재생기 음량을 따라갑니다.

## 텔레그램 채널

북오아시스 `bookoasis_telegram_video` 플러그인에서 **동영상 부분**을 옮겨 왔습니다(PDF/이미지/브라우저 직접 재생은 제외).
서버가 [Telethon](https://docs.telethon.dev)으로 텔레그램에 계속 붙어 있으면서:

- **색인**: 채널의 동영상 메시지(움짤·스티커·둥근 영상 메시지는 제외)를 `data/telegram.db`에 기록합니다. 이미 색인한 채널은
  **목록을 DB에서 바로** 보여주고, 새로 올라온 것은 뒤에서 받습니다(2분에 한 번, 다음에 열 때 보임). 목록을 내리면 더 오래된
  메시지를 400개씩 훑는데, 다음 페이지 몫은 미리 뒤에서 훑어 둡니다. 홈 줄은 채널들을 동시에 불러옵니다. 그래서 오래된
  영상이 많은 채널은 처음엔 개수가 "N개+"로 보이다가 내릴수록 늘어납니다. 제목은 캡션 첫 줄 → 파일명 순.
- **재생**: 브라우저의 Range 요청을 텔레그램 파일의 해당 위치부터 그대로 받아 넘깁니다(탐색 가능, 서버에 파일을 저장하지 않음).
- **서버 변환 (ffmpeg)**: 틀기 전에 서버가 `ffprobe`로 그릇·코덱을 보고 브라우저가 못 여는 것만 ffmpeg로 바꿔 보냅니다.
  형식 확인은 영상마다 한 번만 하고 `data/telegram.db`에 남기며, 상세 화면을 열거나 재생 버튼에 마우스를 올리면 미리 해 둡니다.
  받은 조각은 동영상 캐시(아래)에 남아서 형식 확인과 실제 재생이 같은 부분을 텔레그램에서 두 번 받지 않습니다. 재생 화면 아래 표시로 어느 쪽인지 보입니다.

  | 파일 | 보내는 방법 | 표시 | CPU |
  |---|---|---|---|
  | mp4 + H.264/AAC, WebM(VP9/Opus) | 원본 그대로 | `DIRECT` | 없음 |
  | mkv·avi·ts 안의 H.264 + AAC/MP3 | 다시 압축하지 않고 mp4로 포장만 | `서버 변환(포장만)` | 거의 없음 |
  | H.264 + AC-3/E-AC-3/DTS/FLAC 음성 | 영상은 그대로, 음성만 AAC로 | `서버 변환(음성)` | 적음 |
  | HEVC(H.265), 10비트, MPEG-4/XviD 등 | H.264로 다시 압축 (1080p까지) | `서버 변환(H.264)` | 많음 |

  변환은 파일을 저장하지 않고 조각난 MP4로 바로 흘려보냅니다. 그래서 변환 중인 영상에서 아직 안 받은 곳으로 탐색하면
  그 위치부터 새로 변환합니다(1~2초 걸림). 한 사람이 보는 변환은 하나뿐이라 탐색하면 이전 변환은 끄고, 서버 전체로는
  동시에 3개까지(`MP_MAX_TRANSCODES`). 형식을 알아내지 못한 영상이 원본으로 안 나오면 자동으로 H.264 변환으로 다시 엽니다.
  ffmpeg가 없으면 예전처럼 원본만 보냅니다(설정 > 상태에 표시). 다른 위치의 ffmpeg는 `MP_FFMPEG` / `MP_FFPROBE`로 지정.
- **Safari(아이폰·아이패드·Mac)**: Safari는 길이를 모르는 변환 스트림을 열지 못해서, 같은 변환을 **HLS**(조각 파일 +
  재생목록, `data/hls_tmp/`)로 만들어 보냅니다(재생 화면 표시 `서버 변환(…) · HLS`). 또 Safari는 원본으로 여는 형식이
  좁아서(MP4 안의 MP3 소리는 처음 몇 초를 못 냄, WebM·VP9·AV1·Opus·FLAC은 기기마다 다름) **H.264 + AAC MP4만 원본**으로
  보내고, 소리가 다르면 소리만 AAC로(`서버 변환(음성)`), 영상이 다르면 H.264로(`서버 변환(H.264)`) 바꿉니다.
  Plex도 Safari에서는 같은 기준으로 원본 재생을 고릅니다(그 밖에는 Plex 변환). Chrome 등은 그대로입니다.
  조각 파일은 2분 동안 요청이 없거나 다른 영상을 틀면 지웁니다.
- **사진**: 채널의 사진(압축 사진)과 이미지 파일(JPG/PNG/WebP/GIF 등, 40MB까지)도 색인합니다. 채널 화면의 **[보기]**에서
  전체/영상/사진을 고르고, 사진을 누르면 **뷰어**가 열립니다: ←/→·화면 양옆 버튼·옆으로 밀기로 이전/다음, 두 번 누르기·휠·
  두 손가락·+/−/0으로 확대, 확대한 채로 끌어 이동, Esc·아래로 밀기·뒤로 가기로 닫기. 원본은 처음 열 때 텔레그램에서 받아
  `data/telegram_images/`에 두고(합쳐서 1GB 넘으면 오래 안 본 것부터 지움), 받는 동안에는 썸네일을 흐리게 먼저 보여 줍니다.
  홈의 "최신 영상" 줄에는 영상만 나오고, 검색은 영상/사진 줄로 나눠 보여 줍니다. 이 기능 전에 훑은 채널은 사진을 찾으려고
  처음부터 한 번 다시 훑습니다.
- **채널 종류**: 설정 > 소스 > 텔레그램의 채널 목록에서 채널마다 **영상+사진 / 영상만 / 사진만**을 고릅니다. "영상만"이면
  사진이 목록·검색 어디에도 안 나오고 [보기] 칸도 숨깁니다("사진만"은 반대, 랜덤 재생에서도 빠짐).
- **포스터 짝짓기**: "포스터 사진 → 그 영상 파일" 순서로 올리는 채널이 많아서, 영상 앞(4개 안)이나 뒤(2개 안)에 올라온 사진이
  같은 작품·회차면(제목의 작품 이름과 `S01E09`/`E09`/`9화` 회차로 비교, 이름이 달라도(우리말 제목 / 원제) 회차나 연도가 같고 바로 옆이면) 그 영상의
  **포스터**로 봅니다. 포스터 사진은 [전체] 목록에서 빠지고(사진 보기에는 나옴), 영상에 썸네일이 없으면 썸네일로, 상세 화면에서는
  포스터로 쓰입니다. 회차가 다르면 짝짓지 않습니다. 텔레그램은 파일을 다 올린 시각을 메시지 시각으로 잡아 큰 회차는 포스터보다 한참 뒤
  시각이 되므로, 이름·회차가 맞으면 12시간까지 봅니다(연도만 맞을 때는 30분). 결과는 서버 로그에
  `텔레그램 포스터 짝짓기: 채널 … 영상 N개 중 M개에 포스터`와 짝을 못 찾은 사진 몇 개(옆 영상 제목과 함께)로 남습니다.
- **썸네일**: 메시지의 작은 미리보기를 처음 한 번 받아 `data/telegram_thumbs/`에 저장합니다. 목록을 훑을 때 받은 메시지를
  기억해 두었다가 다시 요청하지 않고, 새로 색인한 영상의 썸네일은 화면이 달라기 전에 뒤에서 미리 받습니다(동시에 4개까지).
- **이어보기**: 텔레그램엔 시청 기록이 없어서 재생 위치를 이 서버 DB에 저장합니다. 30초 넘게 보다 만 영상이 홈 "이어보기"에 나오고,
  95% 넘게 보면 본 것으로 표시됩니다.
- **나눠진 파일**: 큰 영상을 `이름_0000`, `이름_0001`…(또는 `.001`, `part2`, `CD2`)로 나눠 올린 경우 같은 채널의 조각을 한 묶음으로 봅니다.
  두 번째 이후 조각을 재생하면 "N개 중 몇 번째 파일인데 재생할까요?"라고 묻고 [첫 번째 파일부터]도 고를 수 있습니다
  (그 조각을 보던 중이거나 앞 조각을 다 봤으면 묻지 않음). 한 조각이 끝나면 다음 조각을 이어서 재생합니다.
- 로그인 세션은 `data/telegram_<소스id>.session`(권한 600)에 남습니다. **이 파일은 계정 열쇠와 같으니** 남에게 주지 마세요.
  설정에서 [로그아웃]하거나 소스를 지우면 텔레그램의 "활성 세션"에서도 빠지고 색인도 지워집니다.
- **`cryptg`**(requirements에 포함): 텔레그램 데이터 복호화를 C로 합니다. 없으면 순수 파이썬이라 2MB 복호화에
  약 300ms(약 7MB/s)가 걸리고 그동안 서버의 다른 요청까지 멈칫합니다. 있으면 약 20ms(약 90MB/s). 빠져 있으면 설정의
  텔레그램 카드와 서버 로그에 경고가 나옵니다. x86_64와 ARM 모두 미리 빌드된 패키지가 있어 따로 빌드할 필요 없습니다.

## 동영상 캐시

텔레그램 영상과 Plex **원본 재생** 파일(변환 없이 보는 파일)은 512KB 조각으로 나눠 받습니다 (`media_cache.py`).

- **본 부분은 디스크에 남김**: 다시 보거나 이미 본 곳으로 탐색하면 텔레그램/Plex에 다시 가지 않습니다. 서버 변환(ffmpeg)과
  형식 확인(ffprobe)도 같은 캐시를 읽습니다. 사용자끼리 같이 씁니다.
- **앞쪽 미리 받기**: 재생 중에는 지금 위치보다 몇 분(기본 3분, 영상 비트레이트로 계산, 4~128MB) 앞까지 뒤에서 여러 조각을
  동시에 받아 둡니다. 텔레그램은 요청마다 왕복 시간이 있어서 한 줄로 받을 때보다 빠르고 끊김이 줄어듭니다.
  (텔레그램 계정당 동시 조각 요청 6개, Plex는 파일당 4개)
- **용량**: 기본 20GB. 넘치면 가장 오래 안 본 영상부터 통째로 지웁니다. 위치는 기본 `data/cache/`.
- 관리자 **설정 > 캐시**에서 켜고 끄기, 폴더, 최대 용량, 미리 받기 시간을 바꾸고 사용량을 보고 비울 수 있습니다.
  캐시를 끄면 Plex는 예전처럼 그냥 중계하고, 텔레그램은 미리 받기만 메모리로 합니다.
- Plex 변환(HLS) 재생과 IPTV 라이브는 캐시하지 않습니다. 소스를 지우면 그 소스의 캐시도 지웁니다.

## 재생 방식

- **IPTV**: 원래 플러그인과 같은 규칙. `.ts`/`output=ts` → mpegts.js, `.mp4/.webm…` → `<video>`, 나머지 → hls.js.
  `.mpd`(MPEG-DASH)는 dash.js로 틉니다(처음 DASH 채널을 열 때만 불러옴). 중계로 받을 때는 서버가 MPD의 기준 주소(BaseURL)를
  원본 절대 주소로 바꾸고 재생기가 조각 요청을 다시 중계로 감쌉니다. **DRM(암호화)이 걸린 DASH는 재생하지 않고** 그 이유를 보여줍니다.
  원본 주소로 먼저 틀어 보고, 막히면(CORS 등) `/api/stream` 중계로 한 번 더. 그래도 안 되면 그 채널은 "안 나옴"으로
  표시(편성표·서랍에서 흐리게)하고, 망가진 MSE가 다음 채널까지 막지 않게 `<video>`를 새로 만듭니다.
  **재생 중에 끊겨도** (예: 재생목록은 열리는데 영상 조각만 CORS로 막혀 `fragLoadError`) 직접 연결이었다면 서버 중계로
  바꿔 이어 보고 그 채널은 다음부터 처음부터 중계로 엽니다. 중계로 보다 끊기면 3번까지 자동으로 다시 붙습니다.
  `#EXTVLCOPT:http-user-agent` / `http-referrer`가 있으면 중계할 때 그대로 실어 보냅니다.
- **Plex**: 브라우저가 그대로 틀 수 있는 파일(mp4+h264+aac, webm+vp9+opus, 음악 mp3/flac…)은 **원본 그대로(Direct Play)**,
  아니면 Plex 트랜스코더 **HLS**(`/video/:/transcode/universal/start.m3u8`, 자막은 영상에 입힘)로 받습니다.
  30초 넘게 보다 만 항목은 그 위치부터 이어보고, 10초마다 `/:/timeline`으로 진행 위치를 Plex에 알려서
  Plex 앱의 "이어보기"와 시청 기록이 그대로 맞습니다. 에피소드·곡이 끝나면 다음 화/곡을 이어서 틉니다.
- **자막 (Plex)**: 재생 화면 오른쪽 아래 **CC** 버튼(또는 `C`)으로 자막을 고르거나 끄고, 글자 크기(작게/보통/크게)를
  바꿉니다. 고른 자막은 Plex에도 저장돼서 Plex 앱과 같은 자막이 선택되고, 다음에 틀 때도 그대로 나옵니다.
  - **외부 텍스트 자막 파일** (`.srt`, `.smi`, `.ass/.ssa`, `.vtt`): 서버가 받아서 WebVTT로 바꾼 뒤 브라우저 자막으로
    띄웁니다. 원본 재생에서도 나오고, 영상을 다시 불러오지 않고 바로 켜고 끕니다. `.smi`는 한국어(KRCC)를 먼저 고르고,
    UTF-8/UTF-16/CP949(EUC-KR) 인코딩을 알아서 읽습니다.
  - **파일 안에 든 자막, 이미지 자막** (PGS·VobSub 등): 브라우저가 그릴 수 없어서 Plex가 변환하면서 영상에 입힙니다
    ("영상에 입힘" 표시). 이걸 고르거나 다시 끄면 그 위치부터 다시 불러옵니다.
- 편성표 매칭은 원래 플러그인과 같은 순서: `tvg-id` → 채널 표시명(공백·대소문자 무시) → 채널명 그대로.

## 주의할 점

- `/api/stream`과 `/api/plex/…`는 서버가 대신 접속하는 중계라 로그인한 사람만 쓸 수 있습니다. 집 안 네트워크(사설 IP)
  IPTV 서버도 틀 수 있게 일부러 사설 IP를 막지 않았으니, 사용자는 믿을 수 있는 사람만 추가하세요.
- `127.0.0.1` 밖으로 열었는데 아직 관리자가 없으면 **가장 먼저 접속한 사람이 관리자가 됩니다.** 서버를 띄우자마자 직접
  접속해서 관리자를 만들거나, `MP_USER`/`MP_PASSWORD`를 넣고 시작하세요.
- 재생 엔진(hls.js 1.5.8, mpegts.js 1.7.3)과 아이콘은 CDN(jsDelivr, cdnjs)에서 받습니다. 인터넷이 안 되는 곳에서는
  이 파일들을 `web/` 아래에 두고 `index.html`의 주소를 바꾸세요.
- 브라우저가 모르는 코덱(HEVC, AC3/DTS 음성 등)은 Plex가 트랜스코딩해 주지만, IPTV 스트림은 서버가 변환하지 않으므로
  브라우저가 못 푸는 코덱의 채널은 안 나옵니다.
- 사진 라이브러리는 아직 지원하지 않습니다(사이드바에 안 보임).
